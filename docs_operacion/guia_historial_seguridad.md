# Historial de ingresos como entregable de seguridad

Cada entrada/salida queda registrada con **placa, tipo, método (QR o contingencia), zona y fecha-hora**.

| Necesidad | Dónde |
|---|---|
| Ver los movimientos de un vehículo | Historial → buscar por placa |
| Exportar para investigar un incidente (ej. robo de autopartes) | Historial → *Descargar CSV* |
| Ver quién entró sin reserva en un día | Reporte de seguridad → elegir la fecha |
| Saber quién está dentro ahora | Usuarios (estado Dentro/Fuera) |

**Procedimiento ante un incidente**: 1) anotar placa/hora aproximada, 2) descargar el CSV filtrado, 3) entregarlo a seguridad con el reporte del día. Los registros no se editan desde la aplicación.
